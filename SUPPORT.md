# Support

* **Questions and ideas:** open an issue with the form that fits.
* **Studio does not open or says the server does not answer:** say which address you opened, what `curl http://ADDRESS/api/v1/health` answers and, if the server serves Studio, whether `studio_dir` in `server.cfg` points at the `dist` folder.
* **A page shows something wrong:** say the page, the role you signed in with and, if you can, the answer of the server shown in the browser's developer tools (without any token).

This is a one-person project at its first steps: answers can take a few days.
